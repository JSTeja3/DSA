****** PROBLEM STATEMENT ******

LeetCode:
You are given a string s and an integer k. You can choose any character of the string and change it 
to any other uppercase English character. You can perform this operation at most k times.

Return the length of the longest substring containing the same letter you can get after performing 
the above operations.

Input Format

First line: String s

Second line: String k

Output Format

Print a single integer → length of longest substring having same letter after performing the operations  

Constraints

1 <= s.length <= 10^5

s consists of only uppercase English letters.

0 <= k <= s.length

Sample Inputs

Examples:1
Input: s = "ABAB", k = 2
Output: 4
Explanation: Replace the two 'A's with two 'B's or vice versa.

Example 2:
Input: s = "AABABBA", k = 1
Output: 4
Explanation: Replace the one 'A' in the middle with 'B' and form "AABBBBA".
The substring "BBBB" has the longest repeating letters, which is 4.
There may exists other ways to achieve this answer too.
 
 -->  O(N*N), O(1) - Brute Force
 -->  O(N), O(1) - Two Pointer(Slinding Window)
