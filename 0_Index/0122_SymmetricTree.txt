****** PROBLEM STATEMENT ******

LeetCode:
Given the root of a binary tree, check whether it is a mirror of itself (i.e., symmetric around its center).



**Note**
Solution to this problem is written in leetcode style so kindly visit original leetcode url to test
this code



Constraints:

The number of nodes in the tree is in the range [1, 1000].
-100 <= Node.val <= 100







Sample Input:


Example 1:
Input: root = [1,2,2,3,4,4,3]
Output: true

Example 2:
Input: root = [1,2,2,null,3,null,3]
Output: false










 -->O(N), O(N) - Tree(Iterative)
 --> O(N), O(h) - Tree(Recursive)
 h=height of tree
