****** PROBLEM STATEMENT ******

Given an integer array of size N, find the second largest distinct element in the array.
If no such element exists, print -1.

Input Format

1. First line: integer N

2. Second line: N space-separated integers

Output Format

Print the second largest distinct element or -1

Constraints

1 ≤ N ≤ 10^5

-10^9 ≤ arr[i] ≤ 10^9

Sample Input

6
5 1 4 5 3 2


Sample Output

4

Explanation

Self Explanatory

-->  O(NLogN), O(1) - Brute Force(Sort)
-->  O(N+N), O(1) - Brute Force(Two Pass or Two Loop)
-->  O(N), O(1) - BruteForce(Optimized)
