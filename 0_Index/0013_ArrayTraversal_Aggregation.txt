****** PROBLEM STATEMENT ******

Given an integer array of size N, traverse the array and print:

1. The sum of all elements

2. The count of elements greater than a given value X

Input Format

1. First line: integer T (test cases)

2. Second line: integer N (size of array)

3. Third line: N space-separated integers 

4. Fourth line: integer X

Output Format

Print two integers:

1. Sum of all elements

2. Count of elements greater than X

Constraints

1 <= T<= 10^4

1 ≤ N ≤ 10^5

-10^9 ≤ arr[i] ≤ 10^9

-10^9 ≤ X ≤ 10^9

Sample Input

1
5
1 3 5 7 9
4


Sample Output


Test Case: 1
25
3

Explanation

Self Explanatory


--> O(N), O(1) - BruteForce
