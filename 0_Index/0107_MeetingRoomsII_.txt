****** PROBLEM STATEMENT ******

LeetCode:
Given two arrays start[] and end[] such that start[i] is the starting time of ith meeting and 
end[i] is the ending time of ith meeting. Return the minimum number of rooms required to attend all meetings.

Note: A person can also attend a meeting if it's starting time is same as the previous meeting's ending time.





Input Format

First line: Integer N

Second line: N integers 

Third line: N Integers


Output Format

Print integer value → return minimum rooms required to attend all meetings



Constraints:

1 ≤ start.size() = end.size() ≤ 10^5
0 ≤ start[i] < end[i] ≤ 10^6









Sample Input:

Example 1:
Input: start[] = [1, 10, 7], end[] = [4, 15, 10]
Output: 1
Explanation: Since all the meetings are held at different times, 
it is possible to attend all the meetings in a single room.

Example 2:
Input: start[] = [2, 9, 6], end[] = [4, 12, 10]
Output: 2
Explanation: 1st and 2nd meetings at one room but for 3rd meeting one another room required.









 --> O(N*N) O(1) - Brute Force
 --> O(N*log(N)), O(N) - Priority Queue
