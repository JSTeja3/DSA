****** PROBLEM STATEMENT ******

Given a binary array nums, return the maximum number of consecutive 1's in the array 
if you can have at most 'one' 0's.

Input Format

First line: integer N

Second line: N space-separated positive integers

Output Format

Print a single integer → length of longest substring of 1's having atmost 1 zero 

Constraints

1 <= nums.length <= 10^5

nums[i] is either 0 or 1

Sample Inputs

Example 1
Input: nums = [1,0,1,1,0]
Output: 4
Explanation: The subarray [1,0,1,1] contains at most one 0 after shrinking appropriately.


Example 2

Input: nums = [1,1,1,1]
Output: 4


Example 3

Input: nums = [0,0,1,1]
Output: 3

 -->  O(N*N), O(1) - Brute Force
 -->  O(N), O(1) - Two Pointer(Slinding Window)
