****** PROBLEM STATEMENT ******

Given an array of positive integers of size N and an integer K, find the length of the longest contiguous subarray whose sum is exactly K.

Input Format

First line: integer N

Second line: N space-separated positive integers

Third line: integer K

Output Format

Print a single integer → length of the longest subarray with sum K

Print 0 if no such subarray exists

Constraints

1 ≤ N ≤ 10^5

1 ≤ arr[i] ≤ 10^4

1 ≤ K ≤ 10^9

Sample Input

7
1 2 3 1 1 1 1
3


Sample Output

3

Explanation

Subarray [1, 1, 1] has sum 3 and maximum length.


-->  O(N*N), O(1) - Brute Force
-->  O(N), O(1) - Two Pointer
