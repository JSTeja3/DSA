****** PROBLEM STATEMENT ******

You are given an integer array nums.

Count the number of contiguous subarrays where the maximum element in the subarray 
is strictly less than k.

Return the total number of such subarrays.

Input Format

First line: Integer N;

Second line: N Integers 

Third line: Integer k;


Output Format

Print a single integer → Count of Subarrays with max less than k

Constraints
1 ≤ nums.length ≤ 10^5
1 ≤ nums[i] ≤ 10^9
1 ≤ k ≤ 10^9

Example

Input:
nums = [1,3,2]
k = 3
Output:
3
Explanation:
Valid subarrays:
[1]
[2]
[1,2]

 -->O(N*N), O(1) - Brute Force
 -->O(N), O(N) - Monotonic Stack
 -->O(N), O(1) - Two Pointer
