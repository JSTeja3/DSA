****** PROBLEM STATEMENT ******

Geeks for Geeks:
Given an array arr[] containing both positive and negative integers, 
the task is to find the length of the longest subarray with a sum equals to 0.

Note: A subarray is a contiguous part of an array, 
formed by selecting one or more consecutive elements while maintaining their original order.




Input Format

First line: Integer N

Second line: N Integer values


Output Format

Print integer value → return largest length of subarray having sum 0



Constraints:

1 ≤ arr.size() ≤ 10^6
−10^3 ≤ arr[i] ≤ 10^3








Sample Input:

Example 1:
Input: arr[] = [15, -2, 2, -8, 1, 7, 10, 23]
Output: 5
Explanation: The longest subarray with sum equals to 0 is [-2, 2, -8, 1, 7].

Example 2:
Input: arr[] = [2, 10, 4]
Output: 0
Explanation: There is no subarray with a sum of 0.

Example 3:
Input: arr[] = [1, 0, -4, 3, 1, 0]
Output: 5
Explanation: The longest subarray with sum equals to 0 is [0, -4, 3, 1, 0]





 --> O(N*N), O(1) - Brute Force
 --> O(N), O(N) -  Prefix Sum
