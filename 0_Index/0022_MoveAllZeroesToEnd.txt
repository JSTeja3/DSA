****** PROBLEM STATEMENT ******

Given an integer array of size N, move all 0s to the end of the array while maintaining the relative order of non-zero elements.

Input Format

1. First line: integer N

2. Second line: N space-separated integers

Output Format

Print the modified array

Constraints

1 ≤ N ≤ 10^5

-10^9 ≤ arr[i] ≤ 10^9

Sample Input

7
0 1 0 3 12 0 5


Sample Output

1 3 12 5 0 0 0

Explanation

Self Explanatory


-->  O(N), O(N) - Brute Force
-->  O(N), O(1) - Two Pointer
