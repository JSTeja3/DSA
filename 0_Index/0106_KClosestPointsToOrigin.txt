****** PROBLEM STATEMENT ******

LeetCode:
Given an array of points where points[i] = [xi, yi] represents a point on the X-Y plane and an integer k, 
return the k closest points to the origin (0, 0).

The distance between two points on the X-Y plane is the Euclidean distance (i.e., √(x1 - x2)2 + (y1 - y2)2).

You may return the answer in any order. The answer is guaranteed to be unique (except for the order that it is in).




Input Format

First line: Integer N

Second line: N pairs of integers 

Third line: k Integer


Output Format

Print integer of integer array → return K pair of integers(representing points) close to origin

Constraints:

Constraints:

1 <= k <= points.length <= 10^4
-10^4 <= xi, yi <= 10^4







Sample Input:

Example 1:
Input: nums = [1,1,1,2,2,3], k = 2
Output: [1,2]

Example 2:
Input: nums = [1], k = 1
Output: [1]

Example 3:
Input: nums = [1,2,1,2,1,2,3,1,3,2], k = 2
Output: [1,2]







 --> O(N+k*M)=>O(k*N), O(M)=>O(N) - M being unqiue elements(worst case all are unique) - Brute Force
 --> O(N+Mlog(k))=>(N+Nlog(k)), O(M+k)=>O(N+k) - M being unqiue elements(worst case all are unique) - Priority Queue
