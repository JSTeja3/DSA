****** PROBLEM STATEMENT ******

Given an integer array of size N, delete the element at a specified position P.
After deletion, print the updated array.

Input Format

First line: integer N

Second line: N space-separated integers

Third line: integer P (0-based index)

Output Format

Print the updated array after deletion

Constraints

1 ≤ N ≤ 10^5

-10^9 ≤ arr[i] ≤ 10^9

0 ≤ P < N

Sample Input

5
10 20 30 40 50
2


Sample Output

10 20 40 50

Explanation

Self Explanatory

--> O(N), O(1) - Brute Force
