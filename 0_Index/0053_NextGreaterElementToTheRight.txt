****** PROBLEM STATEMENT ******

Given an array of integers nums, for each element find the next greater element to its right.
The next greater element of an element x is the first element to the right of x that is strictly greater than x.
If no such element exists, return -1 for that position.

Input Format

First line: Integer N (size of array)

Second line: N space-separated positive integers representing nums

Output Format

Print N space-separated integers where the i-th value is the next greater element of arr[i]



Constraints

1 ≤ N ≤ 3 × 10⁴
-10⁹ ≤ arr[i] ≤ 10⁹


Sample Input 1
4
4 5 2 10
Sample Output 1
5 10 10 -1


Sample Input 2
5
3 2 1 2 3
Sample Output 2
-1 3 2 3 -1

 -->  O(N*N), O(1) - Brute Force
 -->  O(N), O(N) - Monotonic Stack
